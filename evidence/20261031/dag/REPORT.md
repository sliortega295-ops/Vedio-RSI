# 八卡依赖驱动 Sol-Agent：本轮交付

## 结论

流水线已实现并在一台机器的8张A100上实跑，但**完整计划尚未验证成功**。
我们提供的接口说明漏写了激活变量前缀及Cache family字段位置，导致Cache六次
机会全部在预检时耗尽，未生成Cache视频。责任在我们的接口说明，不能解释成
Cache方法无效，也不能把少做的任务算成调度加速。

剩余Kernel搜索、Master独立验证、Kernel-only集成及最终验收已完成：原生控制器
为`COMPLETE`，外层研究判定仍为`INVALID_INFRA_TRIAL`。退出后检查另为`REVIEW`。
代码与CPU验证已交付，**不是“整套计划已经成功完成”**。没有重跑A/B/C/D、
增加预算或启动第二组；新的完整一组等待用户确认。

## 实际执行

| 项目 | 本轮结果 |
|---|---|
| 模型 | SANA-Video 2B revision `db5f398b13ca086d09a50ce156c20527773841b1` |
| 工作负载 | 832×480、81帧、50steps、CFG6；原定5个prompt、seed42；每视频1卡 |
| 资源 | 同一节点8张A100-SXM4-40GB |
| 冷启动 | 每prompt独立进程和一次原定1-step warmup；20次加载、20次warmup，没有持久模型 |
| Dense | 5个真实视频；抽样55帧的哈希与历史A全部相同，不代表全部视频像素已比较 |
| Kernel | 4次计数：2次接口预检拒绝，2个候选各完成5视频并通过Executor gate |
| Cache | 6次接口预检拒绝，0视频、0有效质量结论，空frontier交付 |
| Master | 独立检查选中组件的实际源码/图片；新生成5个集成视频并独立验收 |
| 总真实视频 | 20个；正式生成失败0次，没有因重试重复生成 |

最终集成采用本轮Agent独立找到的BF16 dense-attention实现，不含Cache、FP8或NVFP4。
五个原生请求耗时之和为 **640.2012 → 559.3711秒，1.1445×**。该口径排除加载、
warmup和导出；不是把五卡并行完成时间当成模型推理加速。

4个真实生成配置都记录了每prompt 50steps、100次逻辑DiT调用、world size 1。
Master实际接收了组件15张和集成15张带哈希的对比图；最终审计问题为空。
集成及独立复核实际走过原版LPIPS：按全局55对的原规则取样，去重后39对，
最大距离约0.06185。它不是新质量阈值，也不能弥补Cache搜索缺失。

Kernel“lossless”沿用原合同允许32→16bit算术的数学/方法口径，不等于逐bit一致，
更不是所有prompt/seed上的质量保证。

## 修复、验收和未完成项

已实现共享八卡就绪队列、每Executor两个未闭环候选上限、逐prompt抽帧/对比图、
独立LPIPS队列、原生批量看图与哈希绑定、完整五prompt gate、独立验证回执、
父版本/反馈依赖、持久事件和逐秒采样。没有为了占满卡而生成额外任务。

我们自己的缺陷和修复包括：不可变源码所有权、异步参考目录挂载、候选注册格式、
Master审计`points`容器，以及DAG漏记Dense bundle→baseline冻结的边。
v6实际冻结核对了真实Dense，但保留的记录图并不完整；没有伪造修复后的历史边。
执行链长不包含所有规划/传输等待，不能据此声称“一小时一定可达”。

退出后只读检查还发现20个本轮僵尸进程，已归PID 1，不占GPU；8卡均0利用率、
0已用显存。它们的出生时间约在旧回收回执后9.7–20.0ms，支持晚退出回收缺口，
但不能据此确定具体第三方库。没有对PID 1发信号、调试器注入或重启用户任务。

补丁保留早期回收，并在导入模型库前注册最后的退出回收；协调器要求最终回执，
缺失/失败则不再认定生命周期健康。**122项原有测试、39项流水线测试、5项分析
测试通过**。真实远端隔离CPU测试确实产生并回收了晚退出子进程，测试UID无遗留；
0模型视频、0模型API、未批准GPU设备。完整SANA GPU退出验证仍为 **NOT_RUN**，
不能把旧轮20个僵尸说成已经清除，旧轮生命周期核查保持`REVIEW`。

一个短间隔采样测试曾在绘图负载下偶发只收到1次采样；单测和完整重跑通过，
记录保留，未弱化断言。预先审查发现的5项问题已修复；后来补丁未独立重审。
Torch编译回调与导出有单独计时；第三方编译若未经过该回调，仍可能包含在加载/
预热里，未伪造精确归因。完整故障经过见同目录`RUNTIME-INCIDENTS.md`。
