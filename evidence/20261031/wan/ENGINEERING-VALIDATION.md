## 统计口径

- Wan native 请求包含文本编码、去噪和 VAE 解码，结束于视频导出之前。
- 冷加载、候选设置、内部 one-step warmup、编译、导出、视频结构校验、卸载单列。
- 同一 GPU 租用时间拆成互斥阶段，嵌套计时不重复相加；租用时间不等于 GPU 忙碌时间。
- API 时长含服务端处理和传输，多个会话的请求可重叠，不能把累计值称作纯网络等待或总墙钟。
- 激活前没有持续采样 GPU，整轮利用率必须报告上下界，不能把未知区间直接当作空闲。
- SANA A 与本轮 Wan 模型和工作负载不同，不计算两者的因果调度加速比。

## 已知能力边界

当前精度检查要求参数存储保持原生分布，可支持保持原参数存储的激活量化；将参数本身替换为 INT8/FP8/packed 存储的量化仍需要独立的精度合同扩展。不能据本轮声称支持所有权重量化方法。
