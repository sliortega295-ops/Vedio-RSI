It must not be counted as queue/idle in the timing report; remote runner `gpu_job_start` events and prompt file/observer data determine actual stage boundaries. The outer reproduction agent did not change candidate/search logic, restart the Executor, cancel R4/R6, or supply an algorithm/decision hint; it retained the contradictory evidence for natural post-completion correction.
